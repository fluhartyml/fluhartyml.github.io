Tally Matrix Clock

tvOS ambient clock with retro-CRT matrix time display. Live on the App Store.

Tally Matrix Clock turns an Apple TV into an ambient display. Time reads as illuminated colored squares in a matrix layout — four matrices (one 1×3 column + three 3×3 grids) representing each digit. Music plays from the same 80+ station catalog that drives CryoTunes Player, with animated pattern shuffles and cascading glyph rain. Shares the CryoKit data layer with CryoTunes. Requires an Apple Music subscription.
