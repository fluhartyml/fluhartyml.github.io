NightGardDDNS

Dynamic DNS client for macOS and iOS. Self-distributed.

NightGardDDNS is a Swift Package and demo app providing automatic Dynamic DNS (DDNS) update functionality. It monitors your public IP address and updates your DDNS provider (DuckDNS) when changes are detected. Local IP from BSD sockets, public IP from a fallback chain (ipify.org / icanhazip.com / ifconfig.me), DuckDNS API for the update. Self-distributed — not on the App Store because automated background DDNS updates are outside the App Store's preferred app model.
