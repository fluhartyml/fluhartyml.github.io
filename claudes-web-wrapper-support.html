Web Wrapper by Claude

Native SwiftUI wrapper around the book's GitHub Wiki. Live on the App Store.

Web Wrapper by Claude is the first Build-Along app from the X26 Swift6 Bible. It wraps the book's GitHub Wiki in a native SwiftUI shell so readers can browse all 22 Books, the Lexicon, the Index, and the Bibliography inside an app rather than a browser tab. Toolbar with back/forward, bookmarks, and a menu. Includes an Under-the-Hood feature that lets the reader browse the app's own source with tappable Swift identifiers. iOS, iPadOS, macOS, visionOS.
