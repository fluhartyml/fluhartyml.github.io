QuickNote

Minimal quick-capture note-taking app with home-screen widget. Live on the App Store.

QuickNote is a small, focused note-taking app: one note title, a free-form body, a date, and a photo grid. SwiftData persists the notes; a home-screen widget mirrors the three most-recent so a glance from the home screen is enough. Capture-first design — the note title field auto-focuses on new notes so the user can start typing immediately. Photo support via PhotosPicker (no library permission required).
